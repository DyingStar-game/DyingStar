# 0024. Credit every asset beside it, and generate the Credits list from those files

- **Status:** Accepted
- **Date:** 2026-10-03 (code AGPL since 2025-11-09) · **Recorded:** 2026-10-04 · **Updated:** —
- **Deciders:** David Durieux (licence), WarpZone (credits)
- **Evidence:** d65e0f24, c509c303, 5b9ea999, 5c577661, 4309f3bd, 5bb28bd1, d291f207, e5a6818d, cab97d57 (PR #350)

## Context

The code is AGPL-3.0. Assets come from community members and third-party sites with differing
licences; CC BY requires the credit to appear in the game. 32 credit files used their own
spellings, a texture stated the repository's AGPL instead of its own CC0, and CC BY footsteps were
refused for want of a credits screen. The export takes `*.json`, not the `.txt` credits.

## Decision

- **Every sound, model or texture someone made has its credit**: a `.txt` with the asset's base
  name beside it (`<base>_*` for a texture set), one line per author: either
  `Discord - <pseudo> - <numeric Discord id>` (a community member, whose work is under the asset
  licence, so none is written; one pseudo per id) or `<Site> - <author> - <URL> - <licence>` (third party).
- A shared material's credit is the `author` / `license` of its `material.json`; a library's own
  `License.txt` credits its folder. AGPL is the code's licence: never state it on an asset.
- `assets/credits.json` is generated by `tools/generate_credits.py` (stdlib, git-tracked files
  only) and shown by the Credits page in the main and pause menus. Never edit it by hand.
- An asset whose source cannot be found is removed, not shipped (the sand steps, 5bb28bd1).
- Licences: the code is AGPL-3.0 (`LICENSE`); every asset made for the project, community work
  included, is CC BY-NC-SA 4.0 (`assets/LICENSE`, `assets_blender/LICENSE`, d65e0f24), confirmed by
  David Durieux on 2026-10-04. Third-party assets keep their own licence, written on their line.

## Consequences

- On a pull request to develop touching assets or the script, CI validates the credits, rewrites
  the list and pushes it as a bot commit (a fork's pull request fails with the command instead).
- Every sound must be credited; a model or texture only when a branch adds it (most have none yet).
- A change must not hand-edit `credits.json`, add an asset without a credit, write a licence on a
  community member's line, give one Discord id two pseudos, or state AGPL on a third-party asset.

## Rejected alternatives

- Free-form credit files (bare URLs, an HTML snippet): rewritten (5bb28bd1). Reading the `.txt`
  files at runtime: they are not exported.
- Requiring every existing model and texture at once: CI red for everyone (e5a6818d).
- Shipping CC BY footsteps with no credits screen (4309f3bd); AGPL on an ambientCG texture
  (5c577661); regenerating the list by hand on each pull request.

## In the code

- `AGENTS.md`: the rule as contributors read it
- `LICENSE`: AGPL-3.0, the code's licence
- `assets/LICENSE`: CC BY-NC-SA 4.0, the assets' licence
- `tools/generate_credits.py`: parses the credits, writes the list, `--check`, `--validate`
- `assets/credits.json`: the generated list
- `ui/settings_page/credits_page/credits_settings_page.gd`: the Credits page

## Enforced by

- `.github/workflows/credits.yml`: `--validate --new-since` the base, then regenerates.
- `.github/workflows/godot-tests.yml`, job `scene-lint`: `generate_credits.py --check` and
  `test/unit/test_generate_credits_py.py`.
- `test/unit/test_credits_page.gd`: the page in both menus, the shipped list filled.
